# ukbsci-ml

End-to-end machine-learning workflows on UKBAnalytica cohorts —
classification (binary / multiclass / regression) and right-censored
survival — with feature selection, tuning, evaluation (ROC / PR / calib /
DCA / KS / gain & lift / confusion), comparison, and SHAP interpretation.
