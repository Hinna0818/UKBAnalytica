# ukbsci-metabolomics

Metabolomics over-representation analysis (ORA) for UK Biobank Nightingale NMR
metabolite data. Covers metabolite classification, name mapping to MetaboAnalyst,
ORA with a custom or MetaboAnalystR backend, and ggplot2 visualization.
